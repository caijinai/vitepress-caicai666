# 12月26日-阳过与阳康

最近的两周，身边的朋友，同事全都阳了个遍，甚至潮州那边也开始了~奥密克绒有点厉害的啊。
阳了让我自己发现，我对病痛的承受度好低呀。阳了几天，两个室友也阳了，各自隔离，只有猪头一个人没事。但是怕传染，所以也是少交流。每天除了拿外卖，上厕所，也都尽量待在房间，冬至的汤圆也是各自在房间吃的~\(｡•́︿•̀｡\)我真是一个不太乐意接受束缚的人，真的这么让我一直待房间简直是要憋坏了。憋得心情都不好了~
其实我真是个外向型人格，时不时的就挺想跟别人说话聊天。接受别人的信息，表达自己。有时候也从别人的肯定中肯定自己。
周末两天心情特别糟，又没法出门，出门了约谁？大家都阳了，自己在房间，又不想工作，但是玩手机也玩腻了，就不停刷视频。。人生有什么意义。。。。
今天工作了，身体也好多了，跟同事聊聊天。工作也逐个在推进，忽然心情又好咯~忽然也不怎么想朗朗，想也不是充满怨气地了~
想想我们的距离也就走路5分钟的距离，这几天却觉得好远，好陌生。我今天起床忽然觉得这个人对我来说也没啥，好像在生活中隐形的一样。。
