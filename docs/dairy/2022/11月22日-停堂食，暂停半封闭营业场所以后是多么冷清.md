# 11月22日-停堂食，暂停半封闭营业场所以后是多么冷清

在家里待太久实在很压抑，出门走走就感觉心情好多了

希望天河快点放开，没有健身房的日子，我真的太无聊了。下班以后漫长的时间呀~~
