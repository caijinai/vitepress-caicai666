# 7月30日-小心思

增城的健身房，物业那边一直没能交付场地，所以朗哥他们也一直没能开工。这周亚彬找他们过去聊，说后续的计划。让他们8月过去开始开工了。8月份先干着看看进度和效果，如果不理想就先在附近找个健身房先干着，保障生活。希望过年前场地能交付能正常开工吧。
增城到员村的交通路线也挺长的，从家到地铁站要15min走路，地铁上的时间大概40分钟，到了新塘站还要走25min以上才能到他们的地方。单程差不多一个半小时，朗哥说想在那附近租个便宜的房子，增城租房便宜，他说租个单间估计五六百就行。
然后我就emo了，哼，要自己一个人住，要变成周末夫妻了。呜呜🥹我在那哼哼唧唧的，他还说怎么了嘛，也不用每天腻歪在一起的。

嗐，这个人成天都不记得自己说的话，之前还说要省钱，每天地铁往返。我说以后再去增城租房子。他说好，结果现在就要在那边租个房子了。•ᴗ•💧

我说公司过段时间要搬地方了，到时候我想重新租个房子，现在这个房子太小了。他还很意外，以为我一直很喜欢这个房子，哈哈哈。说他要求越来越高了。嗐，那肯定要求要逐步提高嘛，这个城中村，想邀请家里人或朋友过来都不好意思，上次海英过来我都没叫过来。

总之，因为他说要去外面租房子，以后可能周末才回来，甚至以后如果比较忙，我猜一周才回来一天吧。我就emo了，就觉得他是不是腻了，胡思乱想甚至觉得我们时不时会分手，就算结婚以后也会离婚……哎，真的想好多。🫣🫠

今晚下班，他在家等我。我回到家，他说今天没出去就是特地在家等你下班。我还觉得他油嘴滑舌哈哈哈🤭

🥰🥰🥰晚上睡觉前，我洗完澡进房间，他说过来抱抱，然后亲亲，贴贴。关灯睡觉的聊天，我们玩成语接龙和星期天逛公园，哈哈哈，好幼稚。聊着他说想到以后可能经常不在家，今天就想留在家等你下班，多陪陪你。这句话倒是说的很真心，忽然觉得这个人呀心里也有些细腻的心思呀，就是平时都不爱在微信上跟我聊了。我又很矫情于他有没有主动想念我。

忽然又充电成功了~希望以后一切都好好的吧。😘🤪
