# Miss You❤️
昨天他应该要去增城帮忙搬东西，今天要正式开工啦。
本来他计划是在亚彬那里过夜，第二天一早可以上班。我下班以后在沙发坐着，开始emo以后可能要过自己一个人的生活，周末才有情侣生活，桑感~
但是他没带衣服，出汗又多。觉得在别人家里也不方便，所以晚上十点多跟我说还是要回来。我一下子又开心起来了哈哈哈😆
还给他煮了经典油泼辣子面！香喷喷~（默默心里想，哼，住家里不好吗，每天还有香喷喷的面条吃）
他回来以后跟我聊了那边租房的情况，挺便宜的。五六百可以租个单间，不过就是都要押二付一。他想了下，目前这个场地还没有完全交付，工作比较难开展。估计大概率下个月还是得去别的健身房先找工作，到时候可以住宿舍，那现在租房到时候再搬走就得损失押金，押二付一也要1500\+了。最后他觉得不如这个月就先两头跑。（只不过认真算了他的交通费，单程地铁上7蚊\+摩的5蚊，一个月如果去足30天，也要六七百块钱，哎呀，这么想确实在那边租个小单间更实在。忽然对于他想去那边租房的想法也就释怀了。）
他回来洗澡、吃面条，围观我打僵尸。催我睡觉。躺着的时候他抱着我问，见我回来是不是很开心。
我说：嘻嘻，是啊
他：我也是好想你，一想到要在外面住就特别想你 ❤️❤️❤️
然后就kiss kiss，do起来了。
