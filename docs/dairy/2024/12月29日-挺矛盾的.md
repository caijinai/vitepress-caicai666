# 12月29日-挺矛盾的

我不希望跟朗哥斤斤计较钱，也不想为了钱跟他闹不开心
但是，也感觉好累，从第一次借钱给他到现在1年半了。他断断续续在工作挣钱，一直没能稳定下来，也一直没能挣得稍微多点（这个多我指的是例如四五千这样）

我在支付房租，日常吃的，用的，等一切开支。他如果发了工资，出去吃饭他会付。但是他工资也不多。10月中开始过去附近这个健身房干，10月工资400…11月工资2715…😭之前他们工资有激励，他拿到200奖金就会给我，但是没过多久他又没钱花又得要回去。。26号发了11月的绩效工资1415…当天就转我，当天晚上就要回去1000（本来还想要1500🤪哼，离大谱，合着我是理财产品啊，钱转我这里当天就能升值啊）

心里憋屈的，我嘟囔几句，他还说我铁公鸡，气死我了。直接叫他去死，说是他太穷了。😂

这也是另一个矛盾点，也不是他没努力去挣钱，是一来增城这边客流肯定没有市区多，提成也少；二来他又是新入职的，肯定前面两三个月挣得少点。然后他说下年回来得去广汇那边干，但是现在又没有完全交付，又得过上没收入的日子了。。。😮‍💨我心好累。但是让他放弃广汇吗，也不能够啊。不试过怎么行呢。只是那边一直没交付场地，拖了又拖…真的不知道什么时候能大展拳脚

我这满腔的憋屈都不知道该撒哪里去，就算跟他吵，跟他要钱，他就那么点工资我总不能全都搜刮走让他没钱花，而且我也不是穷得没钱花。

我只是这个月得凑10w 去交保费，下年三月也得再交一笔3w 的，今天凑完钱，感觉自己账户里都没啥钱。还好是 vistel 这个月一次性补齐了两期的还款，才轻松点。。

23年应该是6月从优健身离职（我感觉虽然优健身也听他说在亏钱，偶尔发不出工资啥的，但是其他教练有些也干的挺久的样子，当然他们挣多少我不知道。。），7月颓废了一个月没怎么去找工作，8在员村一个新开的工作室白干，那一个好像就是都在派传单，没工资。。9月去花都投靠朋友，朋友画了个大饼给他，结果也没挣多少，每个月两千多工资。10月回来市区找工作，折腾换了几家，还去了趟佛山，被环境和思念劝退。那个时候我决定跟他出来一起住。11月好像是去了猎德一家工作室干，女子普拉提啥的吧，但是没啥客户，干了一个月就不去了。12月好像都没有工作…很颓废的状态，他可能就是觉得快过年了，去干收入也不多吧。后来打了点散工。
年后回来去棠东一家工作室工作，干了两个月？说是客户少，都是学生，然后不干了。后来又去了潭村一家健身房，干的还好吧。后来亚彬给他说要自己搞个工作室在增城，让他一起入股，让他7月份开始去吧，wmm 然后他就辞工了，但是7月来回跑增城也没啥事干的，都是在筹备的杂事。后来8月9月就几乎都没工作…9月忙着搬家来增城，又回了趟河南，10月中才开始工作，12月25才算拿到稍微多一丢丢工资。。。妈耶，健身教练挣钱这么难啊。。。
