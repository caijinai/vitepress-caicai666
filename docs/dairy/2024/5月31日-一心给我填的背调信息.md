# 提离职了
今天真的是奇妙的一天
忽然又收到美央hr的消息，问后续没有收到offer是吗？我说是，问了苏总也不回，挺莫名的。她说她再跟进。我以为只是客套话，或者是他们内部流程有点乱，所以再来问我确认。回答完她我也没放心上，继续跟老刘、大头一起吃陶陶居，逛商场。

一点多，我们吃完逛完，准备各回各家，他们苏总监来找我聊，说语音一下。我说现在就可以，他call过来解释了原因（说是内部有个技术骨干对于产品经理的岗位画像有不同意见，讨论了好久，终于谈妥），谈了薪资（薪资比之前谈的降了点，试用期20k，转正23k）发了offer，确实发到邮箱了！

只是我的心情没有上一次那么兴奋了😂🤣可能被伤过一次。当然内心还是开心的，有收入了，而且医美行业感觉也是有前景的，公司的企业文化整体也不错。

回到家，认真看了offer，回复了。然后处理了一会工作，跟一心在微信上聊了这个事情，下午提离职。已经审批完成。下周一等洪月开离职证明给我。

处理完谢这些事情，平静又恍惚，在这里工作了5年半，终于正式离开了。
