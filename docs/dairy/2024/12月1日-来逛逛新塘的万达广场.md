# 12月1日-来逛逛新塘的万达广场

朗哥今天休假，一般他休假的日子就是我们的饮食高碳日或者放纵日
中午在家里做了焖面吃
朗哥一起床就说晚上出去吃自助火锅，我说好。
吃完焖面，两人各自玩了会手机然后犯困就想着去睡个午觉。emm接着就翻云覆雨了一阵子~
睡个午觉到六点，我好饿。朗哥起来说今晚吃外卖吧。
哼~我一下子就不高兴了，不是说吃自助火锅吗？他说你还真想吃自助火锅啊（哼 ，这个大坏蛋想起一出是一出）
我在客厅喊我饿了我好饿，他也反应慢悠悠的（反正有点起床气的感觉）气死我了，我可能真的偶像剧看太多，我就希望男朋友是非常非常关心女朋友的。怎么可以让女朋友饿呢！
过了一会居然建议去吃沙县，更气。说好的吃火锅变成吃沙县是什么鬼啦，吃沙县我不如去超市买一块五花肉回来炒着吃。我就一脸嫌弃说不要，然后他就逐个问要不要吃披萨、吃牛排巴拉巴拉~我就说要吃火锅。最后他就去美团搜了一下，找到了万达广场一家鲜牛肉自助火锅。然后我们就出门了

有点远，不想骑小电驴了，打车去。

这家店新开的，人挺多，食材也丰富。我们到了以后稍微等了一下，就开始拿肉拿肉拿肉，看啥都觉得新鲜哈哈哈。拿了好多，接着就猛吃猛吃。每次跟朗哥一块吃自助都好紧张，他进食太快了，我也会不自觉加快速度。有时候会感觉进食体验一般，好像还没有好好细品食物的美味。不过100\+的自助餐，食物品质就那样吧，肯定没有单一菜系的做得品质好。但是主打一个吃得开心畅快，牛肉、海鲜、小吃、饮料、小蛋糕、凉菜、热菜、雪糕等等啥都有。我们两个人这么能吃，妥妥吃回本。笑薯，我去拿白菜的时候，看边上有个餐盘里也放了白菜，我就顺手拿了，后来朗哥说那是人家小孩拿不下先暂时放那里的，被你给拿了。你从人家小孩盘子里拿白菜，哈哈哈哈

吃得撑，散散步溜达溜达。去夹娃娃，一入“夹”门深似海，朗哥现在比我还爱夹，路过夹娃娃机都要停留一下。不过感觉全自助的夹娃娃机好坑，成功率太低了，不如游客场里面的高。之前在大润发玩的时候，那边的机器还能承诺9局保中啥的。商场无人看管的这种，夹十几次都不一定能中。还好我们最终夹到了一个比卡丘哈哈哈~~20蚊图个开心

再到外面拍拍照，打道回府啦~
