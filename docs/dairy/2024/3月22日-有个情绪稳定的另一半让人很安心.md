# 3月22日-有个情绪稳定的另一半让人很安心

墙上本来是郎朗买的架子，用免钉胶粘上去的。厨房的墙面其实不太平，而且可能因为最近太潮湿导致胶水有点湿了，不那么粘了。
他当时刚下班回到家，架子忽然哗啦一声掉了，架子上的调料都掉下来了。陈醋是大瓶玻璃瓶的，而且放在最靠外面的位置，直接跌落到地面破了，厨房一地都是洒落的醋。
我忽然有点，意外又不意外的感觉。就总感觉这个架子不稳，但是没想到今天倒了。
他很淡定，说这个架子是不是看我不顺眼，怎么我一回来就掉了😂🤣
然后可能怕我看着心烦，就说：我来弄，你坐那就好了。（忽然好安心的感觉）
虽然我还是过去旁边看着
然后他就把没破的调料瓶拣出来，把地上的玻璃碎扫掉，该扔掉的收拾走，能用的就收拾起来。拖拖地，收拾完才去洗澡。全程也没有什么不好的情绪和言语。
还联想起客厅的架子，那个架子有点晃悠。就怕有一天忽然倒下来。他说万一真的倒下来，你就打电话叫我回来收拾就行。
