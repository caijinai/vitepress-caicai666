# 7月14日-吃吃睡睡又是一个周末

今天早午餐做葱油饼
晚餐肉夹馍
现在对中式面食的制作感觉还行，用面包机当和面机，感觉也不花时间，要是让我全都手揉。我就不大行\(°\-°\)🍜

就是厨房太小了，这租房也小，电饼铛也小，只能在茶几上面揉面，擀面。电饼铛每次只能加热两个饼，效率有点低了

希望以后租个好点的地方，有个大厨房或者岛台，让我好好折腾

这两天都好容易困🥱
早上睡到九点多，然后在床上玩手机，十一点多起来，竟然在朗朗醒来以后我才醒哈哈，他说你怎么睡那么久，像个猪\(´•🐽•\`\)（哼，终于被他逮到机会说我猪）
然后做葱油饼，又要洗碗啥的，弄了一个小时。。吃完我就立刻又犯困了，但还是一起看了几集庆余年。大概三点我困得不行就又去睡觉啦，没过多久他也进来睡。我俩真的是好宅哈哈，宅啊宅啊又睡着了

睡得真舒服，五点多自然醒来又继续玩手机，六点多开始弄肉夹馍，又弄了一个小时，电饼铛真的太小了。。

一边看《功夫熊猫 4》 一边吃晚餐（肉夹馍，炒彩椒）

吃吃睡睡宅宅又是一个简单舒服的周末。这 36 度以上的气温，我是一点出门欲望都没有。emm 辛苦空调了
