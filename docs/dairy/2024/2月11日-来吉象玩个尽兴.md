# 2月11日-来吉象玩个尽兴

- 初二，本来应该是女婿回娘家的。他俩大年三十吵架到现在还没说话，加上外婆家的小孩子都跟着妈妈回饶平了，外婆家里应该是比较静，海英就说不回去吃了。
- 既然这么无聊，就带依凌来吉象玩吧
- 初二，没啥司机出来接单。我加价，依凌小财迷➕铁公鸡，说太贵了，不要加。我们搭公车去。哎呀呀，真机智。
- 我们走去车站，刚到就有公车来，速度也还行，就是在中心医院那边塞车了一阵子（庆幸是搭公车，要是打滴滴不得塞掉好多钱）。
- 三点多到慧如，买了99套票，包两张门票和七八个游玩项目，还挺划算的。但是这个小朋友很爱玩溜滑梯，一直在溜，换着不同的地方溜。光是溜滑梯已经用了一个多小时了。她还遇到一个社牛小朋友，她们结伴一起玩。一起玩了水上碰碰船、勇士塔，她们互相帮助，依凌比较会爬，所以帮助小点的妹妹走过各个关卡。小朋友互相陪着一起玩就更开心。最后在第二层也走了几个关卡，拍了合照。第二层的难很多。我感觉下一次我可以去爬一下试试。
- 傍晚六点多，那个小朋友说要回家了。我看韩江大桥还很塞车，依凌还没玩够，我们套票里的项目也还没玩完，就继续呗。
- vr虚拟游戏，马车，科普馆，嘉年华，游戏币~真的好多项目。玩完已经七点了，天都黑咯，整个游乐场剩下我们了。我问玩得开心不，尽兴不。她点头。😀😀
- 又是预料中的打不到车，去等公车等了好久，一看好多车都过了末班了。还好有两个快线是八点多才末班车。后来等到了，赶紧上车。到南桥超多人上车，司机怕有人逃单，要一个个看着付钱。。。所以在这个站停了好久。好在是快线，从南桥开始就没停站了，一直到市政府才开始报站有停的。
- 到了财富中心，吃“卢家妈妈”。鲜芒奶黄披萨不能少，还加了芝士焗番薯，鸡腿排。点了畅饮，她还混合几种不同的饮料到一个杯子让我猜混合了哪几种。。🤪这顿吃得很饱。这个大小姐一出来玩就舍不得走，吃完晚饭还要各种逛。。。一直逛到九点多了
- 准备回家啦，又双叒叕打不到车啦。扫个电动摩托车骑车回去啦。我车技不行，依凌坐在车后面说好害怕啊，哈哈哈…
- 大概十点，终于回到家啦！这满满当当的一天呀，可真“充实”！
