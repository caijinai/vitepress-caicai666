# 8月11日-爱在生活里

他回到家才想起来忘记帮我买牛杂面，我嘟嘴说在等他带来的晚餐
他就说你等我，我下去给你买。我看他满头大汗，有点心疼。说算了不用了，他没理我直接开门出去。已经一头汗还坚持下去。我是又心疼又觉得甜。

回来以后我们还聊了一下，他说看你在等我带晚餐回来，怎么能让你失望。你看我没有犹豫就立刻下楼去给你买。我要是不买，你能吃什么。

我说要说饿也还好，但是我就会觉得很委屈咯

哈哈。忽然觉得这种直接的沟通真好。而且彼此都互相关心❤️

昨天他睡觉撞到我的头了。我说撞到有一点点痛，他朦朦胧胧说过来，然后我躺过去，他一边懵懵的一边给我揉额头，哈哈哈

今天看完电视剧回到房间就躺着准备睡觉。他好惊奇，你睡着啦？你这就睡啦，你都不陪我聊天。（哈哈哈笑蜀，以前这种话是我说的）然后让我给他汇报今天的生活，然后就闲聊，刷抖音啥的嘻嘻\(\*/∇＼\*\)
