# 7月21日-第一次看朗哥生气诶

今天宅着没出门
我想吃大虾问他要不，他说都行。我说那你下楼拿，他说可以。然后我就美团下单了
过了会，我跟他说，你还有碗没洗。他就忽然一下子有点烦🤣🤣说别什么都他干，后来觉得不对又改口说：好，你等我一样一样干
然后又反悔哈哈，说他下去拿东西，让我洗碗。
我不，我说你答应了下去拿我才下单的。（至于碗嘛，我觉得菜啊肉啊我出钱买了。这么热的天在闷热的小厨房里做饭这么辛苦，最后洗碗还得我。那我图啥啊。。）我说那你每次都不立刻洗。他就说那明天再洗碗\(￢\_￢\)（哎妈呀这个懒鬼）
美团到了给我电话，朗哥第一次没有积极主动地弹起来要去拿。而是不说话，有点扁嘴🤣我说：朗哥，快，去拿啦。他开玩笑地表情夸张地表现出烦躁的样子，然后一边走向门口，一边说“好烦啊”🙄
晚餐做好喊他吃饭，他也不积极，躺床上玩手机。我又去房间叫：朗哥，开饭啦。他才起来不情不愿说好。还哼了一下。我摸摸他肚子说：怎么啦，不开心啊。🥹好咯，笑一笑过去咯
吃晚餐的时候，发现他也不爱吃虾，一直在吃五花肉炒青椒🤣嗨，行吧。以后虾我就自己的时候再吃吧
饭后，他说明天还要去增城，怕起床晚了没空洗碗，就去洗了。啧啧，男德满分。
接下来是导致我内耗的环节
他发现垃圾桶有积水导致很臭，他告诉我垃圾桶以后不要挨着墙放。说有积水在垃圾桶会很臭，他被熏得干呕了。然后把垃圾桶冲水了，又拎了点水冲厨房。过程都是语气平和，陈述事实。但是我就觉得像在责备我\(◞‸◟\)🥹emm 这一趴确实是我自己内耗。。。。经常把错误往自己身上揽，被人纠正就感觉是在被批评🥲
