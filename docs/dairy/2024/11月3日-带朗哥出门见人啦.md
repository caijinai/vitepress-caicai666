# 11月3日-带朗哥出门见人啦

仰芬约爬白云山，让我带上男朋友去见面。好吧，之前她明里暗里说得带出来看看了~\_~
朗哥这周休息两天，我让他安排一天跟我去爬白云山，约了大学同学。他说好
增城去市区还是真的远啊，本来想地铁➕打的过去的，但是要1\.5h。。所以当天起个大早去倒腾搭地铁\(╥﹏╥\)
朗哥前一天晚上看直播看到三点才睡觉，早上八点多就被我叫醒了😹他说打车去吧，打车才50\+，地铁过去两个人再打车也要三十几了。嗨～行吧，那就打车
打车挺快。50分钟就到南门了。朗哥这头猪还在车上睡了一觉，我真的老羡慕他的睡眠质量啦！然后下了车就随便找了个地方把身上的卫衣换成短袖😂男生真好，公开地方就可以换衣服🤔
大家到齐以后，朗哥就忽然开启了一个社交开关🫡就会相对热情能聊，emm 演员模式。（晚上回来还问，我今天表现怎么样啊，哈哈）
一路上他给我们拍照，还特别会找角度找背景，指挥我们换动作哈哈，还一直叫我们多拍照😳给仰芬一家拍了美美的全家福 o\(^▽^\)o
慢慢走，一直走到了摩星岭，我还是第一次买摩星岭的门票进去到最顶呢。摩星岭里面竟然有一小段扶手电梯上山顶，广州政府真有钱。
朗哥动一动就一身大汗，臭哄哄的🤦‍♂️猪头说一路上都熏到她了😰
下山我们搭的缆车～缆车只要20蚊呀原来。我都不太敢往后看。一看就是一片树林，脚软。但是缆车好舒服又快，几分钟就溜到云台花园门口了。
在对面随便找了一家店吃饭，味道真一般，白切鸡的鸡皮里面脂肪多得不行，厚厚一层。
好咯，然后各自回家咯
回来是打车去地铁站，再地铁回来。但是那个司机疑似兜路了，明明地铁挺近的，他走了20蚊还没到。。朗哥看到淘金站赶紧说要下车。返程一共花了36。。emm •ᴗ•💧打车也就50多？不过这个时间点打车堵车～
