# 2025年3月22日-最近的求职焦虑

记录一下最近焦虑的心情，以及开解一下自己。让自己不要焦虑，哈哈哈<br>
开年到现在一个半月了。面试只有3个。<br>
第一个招的其实是AI产品经理，做CMS系统，对海外的。五岳信息科技。2月15日面试，跟我面试完以后觉得行业偏差有点大…哎<br>
第二个是讯猫，做ETC业务的。3月5日面试，那天还下着雨。第一面是去粤通卡营业厅跟他们讯猫的项目经理面试的，问的问题主要是需求管理相关的，还要我展示作品和PRD文档。我感觉自己应答得还不错，对方也满意，当场就说要让甲方复试。不幸运的是，甲方那边一直在开会，不知道什么时候结束。只能让我先回去，再约甲方的时间过来复试。这个项目经理一副我已经准备入职的样子，跟我说他们要搬办公室，问我家里远不远，过来方不方便，是否在广州长期发展，薪资要求啥的。结果一周又一周过去了，也没半点消息。我在boss上问HR，一直未读。后来打了电话过去，说是项目经理也没通知她。这周去看，岗位关闭了~人生啊。<br>
然后这等待的一周又一周里，一个面试邀约都没有。boss上看到的岗位也是差不多都是那些，能投的都投了。每天早上起床都会先emo一下，觉得自己的人生漫无目的，存款一天天在变少，工作还是未知数。GAP的时间也一天天叠加，面试官都开始问你从去年9月到现在都没有找到合适的工作啊。接着是坐到电脑前登录boss，看着几乎没变化的岗位，看着一个个我的能力经验不匹配的岗位，陷入内耗焦虑，不自觉地想我会不会以后都找不到工作了。我如果没工作能干点什么来让自己有收入，我甚至想过去做那种临时的、付出重复劳动力的工作。想着想着头脑好紧绷，那种紧绷感是不受控制的。我赶紧让自己忙点别的事情。这种压力没法依靠任何人，只能依靠自己排解。我跟朗朗说，他也是简单安慰一下，说你都工作那么多年了，短时间不工作几个月没什么的。你就当自己就是在放松休息，找工作只是顺便干的事情。哎，有稍微缓解到吧。可是每天都得花钱，我没法淡定。<br>
这周五（3月21日），在午睡呢，忽然有个陌生来电，我想有可能是面试邀约吧。果然是！广东省电力设计院，约我当天下午5:30就面试，线上。这公司名字听着像个国企啊，虽然工资开得挺低的，boss上看是11\-17K。<br>
然后我找求职陪跑老师稍微沟通了一下需要做的准备。但是我内心其实挺丧的，我一看是电力设计院，跟我之前做得业务天差地别的，感觉机会也是渺茫。面试应答的时候，刚开始有点紧张，后来感觉状态好了，但是也有一些回答的感觉不是很到位的地方。emm，反正是面试完以后自己也“内耗式”地想东想西的吧。觉得面试问的问题不难，我有些应答没有发挥好，自我PUA说你看给你机会了你又没好好发挥，你这个垃圾。哎，内心太渴望有份工作了，即使是降薪比较多也没所谓了。另外这个公司是个国企，我心里面还挺想进国企的，我这辈子都没进过国企呀。如果进国企就感觉下半辈子稳了，哈哈。这个时候另一个声音会跑出来说，你没这么走运就这样能进国企的，嗐。<br>
忽然来一个面试就会让我紧绷的神经稍微松一下，觉得人生有点希望的光照进来了，有盼头了。<br>
我找一心帮我分析星盘运势。她说怎么看我的工作都不会有问题。应该4月份会有一些可靠的消息，5月会有一些正式的改变，新的开始。希望吧，希望尽快结束这种求职的日子。
