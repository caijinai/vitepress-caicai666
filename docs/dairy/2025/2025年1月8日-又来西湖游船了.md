# 2025年1月8日-又来西湖游船了

## 10:30

```
今天带依凌大小姐来西湖。因为今天约了伟桦打火锅，想着在西湖玩不会太耗时间，玩完以后去财富中心吃个午饭。可以有比较充裕的时间去伟桦家吃晚饭。
```

  ```
早上八点多起床，打车过来，九点多到西湖。现在附近吃了个早餐，点了灌面和肠粉，就是肠粉的做法看着好奇怪，不像是潮州的做法。果不其然挺难吃的，粉皮是韧的，肉馅味道也很一般，依凌看卖相就不想吃，勉为其难吃了半口内陷就不吃了…差评，以后不来了，店名字叫老晓湾？
```

  ```
吃完就进西湖了，溜达溜达，爬爬山。前段时间有山体滑坡，所以有些岔路都封起来了，可以看到有工人在做加固工程。
```

  ```
我们一路上走走停停，看到一些简单且原始的运动器材，还有些阿姨们在用那些器材稍微活动活动，我们也停下来坐一下，玩一玩。然后又继续走到一个高处，有些漂亮的紫色花，我们就停下来拍拍照什么的。一路闲逛。不过能明显感到这个孩子没那么兴奋了，甚至有种感觉她走了几步路已经想回家了。我想大概以后她不太会想来西湖了。嗐~孩子长大了，需求阈值也越来越高了，边际效应在递减。well，她慢慢会有自己的世界的，顺其自然。
```

   ```
走了一圈又回到了山下，她提出要游船。嗐，我就知道，西湖能吸引她的也就是游船了。那就去吧。
```

   ```
我们今天这个船的方向档位是在背后的，向左走挂右档，向右走挂左档…对于我这个没有方向感的人真的是好难快速准确控制方向，哈哈哈。搞得依凌好操心，一直在那诶诶诶！诶诶！要撞到了。哈哈哈，然后她就自己控制方向了。今天太阳还挺大，有点晒，小孩姐好累哦，要蹬船要防晒要控制方向…
```

   ```
今天不是周末也不是节假日，湖上没什么人，坐在船上看着湖面与湖边的树木和湖中心的凉亭，凉风习习，感觉特别的舒适安逸。我们稍微蹬蹬船让船走到湖中间，然后就停止等着船自己飘。好好享受这平静的湖。中间蹬着蹬着，还被一棵分支垂到湖面的树卡住，进退不得（因为船没有倒挡）。后来手动拨开那根树枝才慢慢可以继续行动。
```

  ```
游湖必备节目，肯定是要撞船啦。但是今天人少船少，不像上次国庆节湖面船多，很容易撞船。后来在桥底下遇到一只龙船，距离很近，他们要过来看懂我们来不及调方向，我们差不多就不动等他们撞过来。然后成功完成撞船指标哈哈。对方说粤语的，外地游客。看到我们船上有个小女孩，还笑嘻嘻地打招呼。
```

  ```
半小时不知不觉也过得挺快，今天没有努力蹬船，我们没有像以前一样绕湖一圈。时间到了就回到起点还船。然后打车去财富中心吃饭啦。
```

 ```
耶~今日份西湖之旅结束。
```

# 又是爱的炒糕粿
回来待几天，蛮无聊的。然后每天能约的人也只有伟桦，哈哈~十几年在外面工作，早就跟很多人没联系了。<br>
前几天又来伟桦家，不想回家吃晚饭，所以在她家吃。外卖了糕粿和菜头粿。伟桦妈妈看我们点了糕粿，说想吃可以买来家里煎着吃。

伟桦约我今天吃火锅，于是我就来了。伟桦妈妈煎了糕粿，两大盘。哈哈哈~好幸福。阿姨做的糕粿没有外面做的那么油腻，鸡蛋放得比较多，比较香。口味比较淡。

伟桦的妈妈真好，嘻嘻<br>
她说：金爱，你以后想吃糕粿就说，来家里，做给你吃

🤩❤️真是让我感受到有妈的幸福🥰呀
