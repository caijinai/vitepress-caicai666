# 1月1日-第一次跟蔡依凌一起过她的生日呢

第一次跟依凌过生日。当时听她说她正好1月1日生日就觉得机会难得，必须得回来。
下午海英给她定了蛋糕，尝试点幸福西饼。依凌自己选了一个紫色的双层蛋糕。傍晚就送过来了。大概八九点，海英去超市买了点薯片零食，又洗了些樱桃放到后面了。
九点多吧，她邀请的小伙伴都来了。然后就一起唱唱生日快乐歌，她许个愿，接着大家一起分蛋糕。蛋糕很漂亮，紫色的。而且上面放的公仔等等装饰，竟然都是巧克力做的，真细节。我本来以为那些都是塑料呢。
我就化身小保姆，给大家切蛋糕分蛋糕，倒饮料，招呼大家吃喝。小朋友们也都吃得挺开心的，但是莫名为了那块写着生日快乐的白巧克力片争起来了，哈哈。
小姐妹们就一起聊聊玩玩到了十点多。明天还要上学，差不多时间都各自回家啦~
