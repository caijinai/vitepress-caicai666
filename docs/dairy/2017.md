# 2017年7月22日-关于塔门岛－赤径

傍晚，开始进入这个小小的小世界<br>
安静，是我对塔门岛最大的印象<br>
安静得似乎不需要跟世界有所关联<br>
这里唯一与世界交联的就是各个码头与快艇<br>
这里能碰到的人是老人与中年的小生意者<br>
这里没有充满互联网与话题的营销,也许是这里安静的原因<br>
六点，通过快艇进入赤径<br>
一个更加偏僻的小村子，一个孤傲的离岛的村子，进入一个似乎是这里唯一的存在的青旅<br>
老板，噢，也不知道他是不是老板，有一种独特的幽默感和傲娇感<br>
老板给我们说规矩：这不准抽烟，抽烟去外面，如果有人在这抽烟，I will get them out<br>
看起来很不近人情的老板却恰到好处地好<br>
他会告诉你：无线网络覆盖的范围不广。这样也好，出来就是要亲近大自然。不要踩死小昆虫，在保证它伤害不了你的情况下赶走它就好<br>
用似乎有点痞气的幽默跟你聊天<br>
看得出也是一个很懂人情世故的人，挺好<br>
星星<br>
拍星星的人<br>

# 2017年7月17日-记第N次想离职的心

是日，领导带着所有的管理层进会议室打游戏<br>
忽然有种…我不知道为了什么要留在这里，不知道为什么要认真去学习提升<br>
反正我的领导们，同事们。讨论专业问题的时候一个两个推脱、吐槽、抱怨<br>
但是到打游戏的时候积极得跟打了鸡血一样<br>
每天工作有三分之一的时间可以聊游戏<br>
但是却没人每天抽出一小时的时间来交流业务专业知识<br>
两点钟的会议才在说：我们没有专业方面的沉淀；大家没有形成共识；大家在制作交流材料时没有一些专业方面的流程<br>
可不是嘛，每天都找机会躲在会议室打游戏…我看不到光明前途<br>
我非常不希望，每次做材料他们只会找菜菜牵头。下面的人做不好只会说你要好好带，好好指导<br>
所以有能力或者说愿意努力的人，反而是最倒霉最需要承担责任的那个<br>
而那些说我不会的人，反而就可以什么都推开<br>
如果是这样，那不如以后多说我不会<br>
中心根本就没有形成一个完整的工作及反馈流程<br>
唉。。😔<br>

## 记录不那么愉快的一天
2017年10月2日 晴（出点小太阳）<br>
上午休假，本以为可以悠闲的上午，被上海那边搅得好不愉快。然后挺怀疑自己的能力，感觉自己真的不是一个合格的产品经理。有时候觉得上海的人也是挺无语的，动不动一点问题就想要人去差支持，而我只想快点结束。<br>
咨询中心的人开始合并到目前的项目中，我开始觉得疲乏，人际关系真的太烦。对这方面我真的没有悟性。最近都在讨论，说咨询的人，阿兰想干掉我们这边的一部分人。本来是咨询中心合并到用户体验中心的，搞得好像是咨询的人侵占了我们的地盘。<br>
建行个银那，最近又经常任务不满，好烦躁。其实最烦躁的应该是自我怀疑。<br>
感觉别人都很优秀。<br>
静仪和悦恒都过了PMP，芊芊八面玲珑、做事自信果断，冼叔的社交能力不用说的，淑颖够强势。反观自己，好像挑不出优点。不知道从什么时候开始，觉得自己很差劲。没有自信，自我怀疑到都要出现心理病了。<br>
什么时候能成为一个人面玲珑，又有自己的原则，有决断力，有自信，有气场的人。<br>
望2017的你比往年更努力，菜！<br>
记不那么愉快的一周中的一天。<br>
Cara.Cai. 蔡金爱 2017.01.10
