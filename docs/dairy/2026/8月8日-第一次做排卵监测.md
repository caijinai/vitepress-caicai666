# 8月8日-第一次做排卵监测

终于出差回来了，赶上排卵期，想了想还是得抓紧做个排卵监测，我想要快点怀孕，这样才能避开出差和裁员的风险。

查了广东省第二人民医院有夜间排卵监测，挺好的，对朝九晚六牛马友好。就是从新塘去有点远，要倒两趟地铁。

到了医院，是个住院部啊，看到都是病房和住院病人一脸懵。后来护士来了带见了医生。医生简单咨询一些情况以后就去检查了，一看我这么大个肌瘤😱然后卵泡不多，问我是不是 amh 值不好，我给了3月份检查的报告是2\.38。医生就说再复查一次，这个值特别重要。我就再抽了血。全都是自费，加上打车，挂号就花了600\+了。

整体来说医生说不太好怀，肌瘤比较大，宫腔环境不好，右边卵泡不多，左边因为肌瘤影响看不清，但是看起来数量也不多。但是可以先试半年，抓紧时间。不行的话再做其他检查和治疗。然后今天的泡泡有18mm 了可以安排同房以后周一再来监测一次，还有医生给我解读验血检查结果（周日收到报告，amh 降到1\.99了，临界值了…）

我问这种如果做手术要等多久能备孕，她说得一年。这倒是比我预期的短，之前以为要两年。

看完医生，整个人轻松了。虽然情况没有太好，但是可能因为终于明确了一些信息，一旦明确，对后来的计划也就有了。肌瘤比较大还医生还是建议先试试，以及如果真的不行，也就等一年，感觉还能接受。虽然 amh 一年以后数值就会更差了😮‍💨

我现在的想法是先排卵监测2\-3个月，还是不行的话，就直接做手术治疗，也不用做其他检查了。反正我的肌瘤已经大到我都有感觉压迫到腹部的其他器官了。然后休养一年以后看指标情况，合适就直接做试管。不能等了。

这种以后就难免要内耗一下，应该在已经确定要结婚的时候就直接去检查，去咨询医生意见。失业那段时间就该把手术做了。只是我实在讳疾忌医，而且看医生好难，光了解该挂哪个科室的号都费劲。这次挂的是生殖中心生育指导的号，还是挺对的。医生也很耐心。

回家跟老公讲了情况，他好淡定😁哈哈，我也很淡定，直接就告诉他医生说我不好怀，得抓紧了，明天再安排一次。他也没说啥，就说好的😓真是个不焦虑的人
