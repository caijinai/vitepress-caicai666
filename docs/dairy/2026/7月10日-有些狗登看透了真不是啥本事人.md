有些狗登看透了真不是啥本事人
我一直觉得，有了 AI 真的是很棒的事情，比起可以做很多事情，有了很多可能，比如我竟然能自己搭一个博客出来了。
但是到现在为止，我依然觉得即使有 ai，每个岗位还是有自己的优势在，ai 就是辅助，主导不了。
但是领导已经癫到觉得开发可以被替代，可以整合。昨天评审对功能内容就没细看，一直在说 ui 做得不好看，油头的 ui 做的更像产品经理（有大病，谁说产品经理是为了产出好看的 ui 的），产品经理输出的原型重点就是体现功能内容，交互逻辑，把业务逻辑讲清楚。如果产品经理的时间用在调 ui 才是脑子有屎。怪不得油头出来的东西都落不了地呢。
这个狗登他觉得有了 ai 一切都很轻松，甚至有轻视所有人的感觉，说到啥都是用 AI 解决。
最恶心的是我说黄经理用的付费模型吧，他还说该付钱就付钱，一个月也就一百多。哇靠，这种人既要又要还抠门，连叫人帮到付拿快递都不先转钱的人，好意思跟我跟我讲这样的话，真是恶心。
才发现这是一个看颜值的狗领导，怪不得公司的设计师明明不算一个优秀的 ui 还被他夸上天，只是因为图做的好看。呵(~\_~💧)
