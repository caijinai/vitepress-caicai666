# 7月17日-记第N次想离职的心

是日，领导带着所有的管理层进会议室打游戏
忽然有种…我不知道为了什么要留在这里，不知道为什么要认真去学习提升
反正我的领导们，同事们。讨论专业问题的时候一个两个推脱、吐槽、抱怨
但是到打游戏的时候积极得跟打了鸡血一样
每天工作有三分之一的时间可以聊游戏
但是却没人每天抽出一小时的时间来交流业务专业知识
两点钟的会议才在说：我们没有专业方面的沉淀；大家没有形成共识；大家在制作交流材料时没有一些专业方面的流程
可不是嘛，每天都找机会躲在会议室打游戏…我看不到光明前途
我非常不希望，每次做材料他们只会找菜菜牵头。下面的人做不好只会说你要好好带，好好指导
所以有能力或者说愿意努力的人，反而是最倒霉最需要承担责任的那个
而那些说我不会的人，反而就可以什么都推开
如果是这样，那不如以后多说我不会
中心根本就没有形成一个完整的工作及反馈流程
唉。。😔
计数：1。或者数到第十次的时候，就可以提辞呈了
