# 7月22日-关于塔门岛－赤径

傍晚，开始进入这个小小的小世界
安静，是我对塔门岛最大的印象
安静得似乎不需要跟世界有所关联
这里唯一与世界交联的就是各个码头与快艇
这里能碰到的人是老人与中年的小生意者
这里没有充满互联网与话题的营销,也许是这里安静的原因
六点，通过快艇进入赤径
一个更加偏僻的小村子，一个孤傲的离岛的村子，进入一个似乎是这里唯一的存在的青旅
老板，噢，也不知道他是不是老板，有一种独特的幽默感和傲娇感
这不准抽烟，抽烟去外面，如果有人在这抽烟，I will get them out
看起来很不近人情的老板却恰到好处地好
他会告诉你，无线网络覆盖的范围不广。这样也好，出来就是要亲近大自然。
不要踩死小昆虫，在保证它伤害不了你的情况下赶走它就好
用似乎有点痞气的幽默跟你聊天
看得出也是一个很懂人情世故的人，挺好
星星
拍星星的人
榄菜的摄影技术
