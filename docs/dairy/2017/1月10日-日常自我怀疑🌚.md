# 记录不那么愉快的一天
2017年10月2日 晴（出点小太阳）
上午休假，本以为可以悠闲的上午，被上海那边搅得好不愉快。然后挺怀疑自己的能力，感觉自己真的不是一个合格的产品经理。有时候觉得上海的人也是挺无语的，动不动一点问题就想要人去差支持，而我只想快点结束。
咨询中心的人开始合并到目前的项目中，我开始觉得疲乏，人际关系真的太烦。对这方面我真的没有悟性。最近都在讨论，说咨询的人，阿兰想干掉我们这边的一部分人。本来是咨询中心合并到用户体验中心的，搞得好像是咨询的人侵占了我们的地盘。
建行个银那，最近又经常任务不满，好烦躁。其实最烦躁的应该是自我怀疑。
感觉别人都很优秀。
静仪和悦恒都过了PMP，芊芊八面玲珑、做事自信果断，冼叔的社交能力不用说的，淑颖够强势。反观自己，好像挑不出优点。不知道从什么时候开始，觉得自己很差劲。没有自信，自我怀疑到都要出现心理病了。
什么时候能成为一个人面玲珑，又有自己的原则，有决断力，有自信，有气场的人。
望2017的你比往年更努力，菜！
记不那么愉快的一周中的一天。
Cara.Cai. 蔡金爱 2017.01.10
