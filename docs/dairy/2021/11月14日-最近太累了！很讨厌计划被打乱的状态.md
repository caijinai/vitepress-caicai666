# 11月14日-最近太累了！很讨厌计划被打乱的状态

今天上郎朗的课。能一边上课一边聊天的感觉倒是挺好的。
	他穿他们的工服显得他胖的特明显，笑死。脸圆的跟小胖墩一样哈哈
	然后就聊了聊他接下来要减脂了，最近长痘了啥的。现在他给我上课可轻松了，我都不用他怎么操心多好呀
	我也胖了，而且核心差了好多！要恢复早训练核心。之前那段核心练得特别硬实的感觉是真的很好！
	有时候对这种关系就还挺恍惚的。前一天我们在一床上热烈地亲吻。下一天我们像普通会员和教练一样聊天上课。
	只不过我觉得他没以前那么关心我了，也不跟我闲聊了，也不跟我聊心里的想法了。不像以前是个演员扮演对我的生活感兴趣跟我聊很多。而我却对那个扮演者当真了，觉得挺喜欢以前那个扮演者的，让我觉得他真诚，简单，可爱。现在在我面前他是他自己了，但是也是真的挺不关心我的。

最近好忙，也怪自己接了外单，周末都没怎么休息。
	想说要恢复早上起床早训，结果才双一个电话来说要讨论报告的调整。就讨论到凌晨十二点了，我担心赶不及就赶紧改好，就凌晨一点多了。早上也实在起不来了。。。然后周一晚上，周二晚上都要开会，做培训。。。好累啊。是真的很讨厌这种计划被干扰无法好好执行的感觉。就好想逃离，但是发现逃离了这些事情一样要做。。。。（忽然发现我挺爱逃避的）
