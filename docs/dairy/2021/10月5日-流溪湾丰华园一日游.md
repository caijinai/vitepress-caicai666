# 10月5日-流溪湾丰华园一日游

- 跟仰芬约今天出来农家乐😃
- 这里还有点好玩，门票也不贵。大人38，还送20代金券可以兑换一些游玩项目
- 挖土机，各种水上项目，游泳，钓鱼啥的。挺适合小朋友。而且有很多休息的地方。凉亭，农家乐煮饭区啥的。后悔没有带点零食来边坐边闲聊🤪
- 中午在里面吃，只有ab套餐选择，味道一般。饭后泡自己带的茶叶，猪头买的白茶，味道还不错。后调有点甘甜。带茶叶和茶具是本次最机智的选择
- 临走玩了小火车，嘻嘻，还可以噢
- 晚餐找了附近的农家乐，顺德菜。味道真不错，有个超级大的糯米鸡，还有野菜。价格也便宜，人均不到60，下次一定要再来试试其他菜
- 下次，直接过来中午饭（顺德公鸡公碗农庄），吃完再进去玩。带点小点心（甚至直接在农庄打包一些能放久的菜比如鱼饼，鱼皮啥的），带个午餐垫和茶具茶叶进去，开水可以跟前台要。小孩子玩，大人坐着闲聊~完美
- 峰峰也越来越活泼啦，虽然还是很冷静的样子👀
