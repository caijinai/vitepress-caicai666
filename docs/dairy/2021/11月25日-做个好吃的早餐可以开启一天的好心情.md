# 11月25日-做个好吃的早餐可以开启一天的好心情

昨晚做了鸡肉饼，造型略有点失败，因为手剁鸡肉真的好累，家里的刀又不锋利🙄，但是加了洋葱味道是真不错。做了几个午餐带，留了一个早餐哈哈哈
	今天吃了牛油果泥涂大列巴，再加上鸡肉饼，磨了杯咖啡喝，一个低卡营养包含蛋白质，优质脂肪的早餐就出来啦。哈哈
	最近阴道炎有复发的迹象，也真是不知道为啥。我挺注意卫生的，上次复查完以后也只跟郎朗做过一次。。。感觉啪啪啪对阴道炎没影响。就是最近降温，然后前天轻断食，身体嘘嘘。然后病毒就又伺机入侵了。唉，以后再也不搞轻断食了，这种为了体重体型的焦虑不该存在。我觉得我每天吃得挺健康的。当然有时聚餐确实吃得多，得控制得改。但是其他时候都挺注重营养搭配的。再加上以后要增肌撸铁，我觉得就算长体重也不是脂肪居多。
	但是自己乱搞的轻断食，也许会对身体有伤害。尤其最近脚痛，感冒，阴道炎都还没好，接了外单又经常要忙。还是好好爱惜身体。先把体重抛开！好好吃饭，好好生活。
