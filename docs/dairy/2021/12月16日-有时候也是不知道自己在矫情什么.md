# 12月16日-有时候也是不知道自己在矫情什么

人家只当你是炮友，以及一个容易说服出钱买课的会员~人家的日常计划里和未来里都没有你。现在不过就是安排你上课的时候没给你配个好点的时间。你究竟要矫情什么。。矫情人家不上课就不找你聊天了。。。矫情人家每次开口不是约课就是约课。。。（敲这段都泪目了，我怎么这么惨。又没做错什么，为什么没人疼爱我。。）
但我就是不舒服啊。。
八点半上课，一小时了➕四五十分钟有氧与拉伸，回家都要接近十一点了。
为什么要我迁就，为什么我要为了满足别人的计划和目标活着。我过了34年有多少时候是为了自己。。不想忍。不喜欢就别勉强
只是一直没能下决心处理这段奇怪的关系。。。。。我自己都看不透自己。
