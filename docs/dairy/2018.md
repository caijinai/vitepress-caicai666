# 2018年8月7日-随想20180807

我想，虽然我们的本性就是好逸恶劳<br>
摊着闲着的日子多么轻松<br>
但是始终我们还是喜欢那个忙碌地为自己喜欢的事做出努力的自己<br>
即使时间被排满<br>
即使坚持十分艰难<br>
即使似乎显得很孤独<br>
但是，你始终因为这样的取舍，得到了进步与满足<br>
——记 一只最近练吉他很勤快的手

# 2018年2月7日-我宁愿孤独终老

火车上看见一家人，一家4口，一对成人，一个老人，一个小孩。听他们说话，应该是潮汕人与广州人结合的家庭<br>
老人语言不是太通，潮州话，普通话，粤语都说，都不是太准<br>
听得出对她的儿媳妇有些意见，大约平时婆媳也有些琐碎矛盾吧<br>
而老人的儿子却似乎对妈妈也是一副高高在上的样子，没什么尊重。真是潮汕大男人典型。<br>
有点好奇最小的小朋友以后会是怎么样的性格<br>
然后，觉得老了还是自己好，别去跟孩子一起生活<br>
我不要老了还要去学习年轻人的语言<br>
我不要去适应多了一个儿媳妇或者女婿的生活氛围<br>
我不要一把年纪了还要去宽容体谅年轻人<br>
孤独是一种自由
