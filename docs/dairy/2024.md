# 2024年12月16日-荔浦芋头包

在老刘的推荐下，我买了3斤荔浦芋头。<br>
为了让芋头能更好地被保存，到货的第二天中午，我就把芋头皮都削了，切小块，每150g分装好，冷冻到冰箱里<br>
同时很想吃芋泥，想做芋泥包。于是拿了一个芋头放到高压锅里蒸熟。高压锅上气以后大概5分钟我就关火，在关火以后，高压锅微微放气的过程中，闻到了芋头香香的味道。看来这个荔浦芋头品质不错<br>
开锅看芋头，很粉！我把芋头放到搅拌机里，加牛奶和糖搅拌成芋泥。这个芋头特别粉，很干。加了快200ml的牛奶才感觉可以搅拌得动。搅拌成泥以后我就放到密封袋里等着一会包包子的时候可以挤芋泥到包子里。本来想着芋泥比较难成型，不好包，所以想着用挤的。但是这个密封袋剪开一个小口挤芋泥以后，把边上其他接口处也崩开了。。<br>
反正最后坚强地把芋泥包进去了。然后包子发酵40分钟，蒸15分钟。哇哦~~太棒了。好有成就感，我立刻就拿了一个吃当是晚餐。自己做的芋泥包子，不会太甜，有香香的芋泥味，好棒棒~
