# 11月20日-因为买错奶茶被生气，唯唯诺诺！哈哈

他竟然给我买一杯抹茶，纯抹茶！加了一大堆冰，还没有小料！！差评到底！😑🙄

气到我了，都不想跟他说话，在一块这么久，居然连一杯我能喝得下去的奶茶都点不出来

我说了他几句哈哈哈。他就很怂，一脸做错事的小孩一样

最后我喝了他那杯波霸，让他喝那杯纯抹茶。后来我消气了，他看着波霸奶茶：我能不能喝一口
哈哈哈！笑死🤣

挑个电影看挑半天，我问怎么这么久，他：这不是怕你不满意嘛

一起看《超凡蜘蛛侠》，他说他想抽烟，怕呛到我

去洗碗，他用钢丝球刷铁锅，问我这样没错吧（早上他用钢丝球刷电饭锅，我赶紧过去阻止了！）

他的总结：你看我唯唯诺诺的，生怕做错了，你不高兴
