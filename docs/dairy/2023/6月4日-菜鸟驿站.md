# 生气的后续
为什么会生气呢？
周五他休假了，然后他约了他的朋友打游戏，一直打到很晚。
我周五又正好加班，一直加到9点多，回到家10点多了，他居然一句都没有过来问。他好像忘了我们默认周五就是要在一起过的。
他发了一句，哦对哦，周末了我都忘了。
然后我就很生气，说你陪你没游戏过吧，别理我了。
然后周五晚上，周六一整天我都没有理他。真的是有气到我。
