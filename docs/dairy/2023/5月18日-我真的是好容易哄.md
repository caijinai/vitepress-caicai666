# 5月18日-我真的是好容易哄

本来对于他说我胖，说快没兴趣了。觉得很羞辱，想着想着就掉眼泪。
本来想周三都不去，整个星期都不去他那了。
结果他一说两句心疼我的话，一说要给我放松，我就觉得心里暖暖。直接就答应了。
我这剧情放电视剧里就是被人骂的吧。

不过他也算不错，下班回来一坐下就跟我说：我喘口气就帮你放松。
然后就用筋膜枪给我放松腰背，仔仔细细从上到下按摩了。还是蛮舒服的。按完问：你的服务结束了，你是给现金还是肉偿
我：没现金呀，只能肉偿了。
然后亲了他一口。
睡到凌晨两点多他才进来，叫我。我正好也醒了。于是又是一趟翻云覆雨。他问能不能s在里面，哎。万一怀孕了我可不想要。。。最后怕s在床上，还是去了厕所。他说本来感觉有点累，一摸到胸晃得厉害，就忽然又很兴奋了。每次的兴奋点都不大一样。
结束以后问我棒不棒，问我腰还有没有不舒服。然后就睡觉了~

不过我这个腰啊，真是不知道咋回事，是不是劳损过度了。。。筋膜枪放松的时候还是有点痛的。
