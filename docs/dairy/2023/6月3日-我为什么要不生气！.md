# 6月3日-我为什么要不生气！

每次只会说对不起，只会叫我不要生气😠。我为什么不生气！一次次的失望，一次次地被忽略！

每次都说自己错了，然后下次继续。只会叫我别生气，连给点承诺都没有！

每次休假就失联，不闻不问的。我是你的客户吗？？只有工作上班的时候才联系？？

每次只有我生气了，才会对我好

我已经要求很低了。
大家工作时间不一样，我没有要求你要每天时时刻刻跟我分享生活日常，没有要求你得给我分担什么困难，没有要求过节要有仪式感，情人节各种节也没要求出来约会聚餐看电影，甚至没要求你过节得给我点杯奶茶，也没要求你得对我无微不至，没要求你得时不时送我礼物给我惊喜。没要求你得晒恩爱，我们谈恋爱谈的像偷情一样我都觉得还好，反正我们没有未来，现在开心就好。
要求低到我觉得自己跟单身没什么太大区别。

我只是希望你能像正常谈恋爱一样，心里有我，会挂念我，会想着我

平时周一到周五如果不上课连面都见不着，每周末一起待着，我觉得是最低需求了。
你倒好，一休假顾着跟朋友玩游戏，完全没把我放心上！

周五加班加了一晚上心情不好，也希望有人挂念自己问一声：下班了没有？怎么这么晚还没回家？
结果加班到九点半，微信空空荡荡没有任何关心

我知道我们不会有将来，那现在在一起的时候就好好的，互相陪伴，互相挂念。

但是感觉其实你根本不需要谈恋爱。你经常自己一个人沉浸在自己的世界里。你只顾自己，简单到有时候回家都不会想着帮我买瓶水，买根雪糕。

你要谈什么恋爱。恋爱本来就要接受束缚，本来就要考虑多一个人的需求。你考虑个鬼
