# 7月12日-前年长疣，今年长鸡眼。左脚有毒

最近昨天脚底有一颗东西，顶着痛。
以为是疣，想着是复发了？我又想着这东西会传染，就挂号去医院处理
医生说是鸡眼。。。长期挤压导致的。呀，我以后要穿宽松的鞋子。一定

这次发现中山六院可以直接在公众号上面定点，还挺方便的。也可以直接在手机上支付费用。

于是我就在手机上定点顺便支付了医药费，发现定点之后给我减免了100多，接近一半的费用还挺好的

去的早看得快，排队敷药什么的也都快点。8:00到那儿，大概9:30已经回到家了。
处理的过程我很紧张，尤其是打针前的那一会儿，因为打麻醉针特别特别的痛。感觉那根针扎的特别深，然后推药水进去的时候也感觉特别痛。心里很慌很难受。虽然就那一会儿，但是太难受了。如果有下次（虽然希望没有下次）我希望朗朗陪我一块去。

这次给我处理的护士特别细心，叮嘱了很多东西。
一个星期不能碰水，可以去买一些防水的贴。不能吃辣的，要清淡饮食。
如果流血了要怎么止血，要长按5分钟再放手，看看会不会流血。
还会配一支药水回家可以用，以免伤口继续感染发炎什么的，他也很细心的叮嘱了药水要怎么喷。说那个药水如果喷在普通的皮肤上，可能会有一些过激反应，所以提醒不要喷太多。

昨天想到要去看医生，就心情不大好，很焦虑，今天看完之后反而没啥了，轻松了。
