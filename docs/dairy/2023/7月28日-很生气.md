# 7月28日-很生气

可能快来姨妈，脾气暴躁！
他又是一天没理我，微信一个多小时没回，回我的时候立刻认错，说太忙了。我真无语。然后说自己已经下班了。尼玛九点就下班，九点半才回消息，好气好气
我一进门直接去洗澡了，不想理他，他跟我说话我也不理了。直接洗澡完进房间
尼玛他竟然就继续在呢玩游戏。。。绝了！！这个男人要来干嘛！！
真的是太难过了，这个人也就平时嘴上说得好听而已，竟然真的就不进来问问我，哄哄我！不想要了！渣男！！

然后过了一会，进来哄了。嘴也笨，只会说自己错了，不要哭啥的。然后就是强吻和那啥。被我推开了好几次。

他一直让我不开心要说出来，我就说你九点就下班了，但是都回到家了也不回我消息。你一天到晚都不关心我。

哎哟，说出来真是都挺幼稚的事情呢。但是心里真是气啊

他一边做一边说，我是真的爱你。我就慢慢心软了，慢慢接受了。。
