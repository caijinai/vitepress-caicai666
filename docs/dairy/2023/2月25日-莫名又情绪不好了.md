# 2月25日-莫名又情绪不好了

周五晚上我莫名又生气了，我自己都看不懂自己这是怎么了。忽然情绪就来了，觉得他一整个星期也没怎么主动找我，没怎么关心我。加上现在他没有自己住的地方，每个周末我们连单独相处的时间都没有，就让我觉得很没劲。（其实我自己都搞不懂自己怎么忽然就来情绪了，可能真的是太太缺爱了）因为忽然生气，对他又是一脸黑。在做有氧，他过来，我简直是懒得摘下耳机理他，结果他开口也是：明天约的七点是吧。。。。然后又看我一脸不想理他就识趣地走开了。后来要走，他看出来我不开心又搞不懂，看着我又不敢看。然后问了句：菜菜要走了呀
我：不然呢，留下来吃宵夜吗

第二天我早上去做有氧，他正好上课，过来聊天。我的情绪还没过去也还是没理他。好在他中午还记得在问我找我聊天。我想想自己也挺过分的，莫名就这样。然后自己慢慢内化，再做做面包，出去玩玩滑板，也就过去了。。

周六上课，他后面都没课了，时间很充足。我到了以后他也不急着上课，跟我聊天，聊聊下午滑板，聊聊他的减脂进度，拍公司的视频，聊日本的网吧可以当住宿宾馆用，配套供应很齐全。还有些有的没得（好吧其实我都忘记聊啥了）他就说那不得跟你聊聊天，又不像以前每个周五晚上还能聊聊。
我：你才知道啊。（有点泪汪汪）
郎：你老说我只会跟你聊约课
我：本来就是啊
郎：那这不是得多跟你聊聊天

于是算是聊了愉快的天吧，上课的时候也一直在聊，感觉训练质量一般（doge）
