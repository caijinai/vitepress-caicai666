# 8月16日-清空冰箱的一顿饭

今天下午请假，过去收拾我的东西
我的东西可真多真多，收拾了好几个袋子。仿佛我才是那个房子的主人，东西比他还多
他帮我提过来，上六楼。累得一身汗，哈哈哈
然后参观了我的房间，东西真多。。
上周末我还买了一些菜在冰箱，还有冰箱里一直放着饺子。不能浪费，于是今晚的晚餐就是清空冰箱。肉，热狗肠，生菜，饺子，青椒。一趟做下来，东西还挺多的。所以我也破例不减肥了今天，吃得很饱。一边吃饭一边看《扫毒3》
然后就是耍手机时间哈哈。我问他怎么不玩狼人杀（他最近几天都在玩），他说：想陪你。❤

过了一会他去洗碗，
我说：真棒。
他：？
我：洗碗，真棒
他：做饭，真棒
哈哈，这就是爱的正反馈吧❤

晚上就是没有悬念的啪啪啪活动，毕竟以后隔这么远，要啪啪太难了。。

穿了黑丝，在沙发上做的~然后他进来陪我睡，聊了会天，就睡到天亮了
