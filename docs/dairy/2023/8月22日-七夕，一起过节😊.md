# 8月22日-七夕，一起过节😊

七夕，他特地搭地铁1\.5小时过来。
他说：七夕怎么能让你一个人过呢❤
他说。陪伴是最好的礼物

晚上9点多他睡着了，他好困，他跟我说他睡一会儿让我叫他起来。结果他一睡不醒，我看他睡得那么香，我也舍不得叫醒他，而且我也困了，我就躺在一起睡了。
但楼上一直有空空空的响声，小孩子一直在上面玩闹。所以我也是很晚才睡着。
四五点他醒了，然后把我叫起床，然后翻云覆雨了一番。
今天say goodbye的时候，他说他说可惜昨天睡得太早了，醒都醒不来，本来准备了故事要讲给我的，还想跟我好好聊会天。
刚刚语音打电话他说让我以后得叫醒他，怎么能不叫醒他呢？
嘻嘻嘻。看来他真的是准备了故事要和我聊天的。
好的，以后就听他的安排，他说叫醒他，那我就把他叫醒起来，让他好好执行他自己的安排。^ω^
