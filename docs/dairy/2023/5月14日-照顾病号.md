# 5月14日-照顾病号

他的感冒反反复复的。
我晚上八九点钟打包了米粉，烤了个鸡腿过去给他吃。
他睡到快10点起来。迷迷糊糊的。
手摸我的手，我感觉体温很高，应该是发烧了。
看他这么难受，我就安静的看视频，也不怎么找他聊天了。
10点多我困了，我们就到床上睡觉了。
结果发烧头疼的他竟然还有精力do。。。绝了。但是说怕传染给我，就没亲我。do完睡了，他抱着我，他身体烫的呀，一会我就流汗了。他半夜睡不着，又起来吃东西，找手机。。。。绝了，真是。还好半夜摸身体退烧了。
第2天起床，他说饿了，我给他蒸了糯米鸡和烧卖吃。

这种照顾他的感觉真好。我大概是有什么奇怪的讨好型人格，伺候别人照顾别人，让别人舒适，就觉得挺开心的。哎，怎么这样。
