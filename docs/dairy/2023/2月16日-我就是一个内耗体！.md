# 2月16日-我就是一个内耗体！

矫情！内耗！每天为了点小事生气！难过！真是救命！
我为什么不能碰见一个爱我的人！好难过！

刚才认真想，哭的好伤心，伤心到我自己都不理解。
感觉我是不是有点心理障碍。从小就会这样，小学的时候就开始了，有时候遇到不受关注，被不公平地对待的情况，就会设想全世界的人都对我不好，然后就使劲地哭，感觉这个世界上没人爱我，没人很爱很爱我。我渴望被浓烈的爱包围。（不过更伤心的是，这个世界上确实没人爱我）

我很爱他么？也不一定，只是想到他不爱我很难过
只是我无法接受他说我们在谈恋爱，却一点偏爱也没给过我。只是我无法接受我每天都想知道他在干嘛，想和他分享日常，他每天开口就是跟我约课，好像我只是他随便的一个普通的会员（甚至不如一个新会员）。只是他给别人上完课就在和人家聊天分享他的减脂视频，我要知道却只能自己去翻他们店的公众号（哼！我才懒得看！）
