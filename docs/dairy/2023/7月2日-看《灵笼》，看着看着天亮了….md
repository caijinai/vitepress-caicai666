# 7月2日-看《灵笼》，看着看着天亮了…

周六，去骑车。他去面试以后就回家睡觉。真的，他真的好乖，哈哈哈。除了打打游戏，也不去哪里。就宅着睡觉。

我回去，他才刚醒。醒来的时间倒也刚好，我都想着是不是会到了门口，他在睡觉，门又反锁。我在门口狂打电话也没人接呢。。

今天出门穿了他的黑色短袖，回来又拿了他的无袖背心当睡衣。他说：你把我黑白衣服都穿了，我没衣服穿
他要出门去吃饭，说下去一趟上来，衣服又得洗。我把我今天穿过的短袖给他，说让他穿这件。闻了闻，倒也没啥汗味。就说还好没啥味道。他：都是你的体香。哈哈哈

他竟然主动提说要买点零食上来，我说要毛豆。楼下没有，他走到都市广场那里去买了。嘻嘻，真好。kiss一个奖励。以及还主动买了鸭脖，以前嫌弃鸭脖没肉哈哈，可能看我经常吃。倒是也接受了

一起看《灵笼》，周五看了几集了。接着看，剧情好紧凑，情节好看。画面也漂亮。里面好多不同的噬极兽，有点在看山海经的感觉。

然后我们就一集接一集不停地看，ipad没电就插电看。看到倒数第二集，一看时间，凌晨五点了。。。啧啧啧！妈呀，这动漫好看到，我对时间的感觉都迟钝了。但还是想看最后一集。看到六点，我们还讨论了一下剧情。我困得不行了，直接睡了。一觉醒来，中午十一点多，上个厕所继续睡。一点多，他要去面试，我才醒来。

emm生物钟乱套的一天。但是一起看好看的动漫，一起讨论剧情。好开心😊
