# 5月28日-烧卖喊你起床啦

昨晚一起看 银河护卫队2，好看。看完稍微聊天一会，我就困了想睡觉。他就继续玩手机到三四点
早上，我：你昨晚是不是很晚睡觉
他：也没有很晚吧，三四点
emm？三四点还叫不晚？

早上我十点就醒了睡不着，起来蒸烧卖和糯米鸡吃早餐。然后看书，在他家看书特别好，周围很干净，也没那么多杂物，没其他人干扰。
他的闹钟响了好多次，快十二点又响了。他还想赖床，我去开他的们喊他：起床啦，我蒸了烧卖。
他（略带高兴的语气）：蒸了烧卖？那我就起来吃
哈哈哈好可爱，怎么像个小孩一样
起来他还惦记着昨天给他说得香蕉面包，也拿了面包吃。
我还给他弄了杯冰美式。看他喝得好吃得好，我就还挺开心的。感觉我们之间是有联结的。
他要去上班，亲一个，kiss以后就拜拜啦~

还用蛋挞皮和香肠做了这个给他吃，嘻嘻。他说好吃，然后食量惊人地一下子炫一半下去了哈哈哈。他还说自己有个缺点，一吃东西就停不下来。确实。。我放抽屉里面的零食是想着他饿了可以吃的，结果他昨天就吃光了😂

昨天他本来还让我不用过去了，他想约朋友周末打游戏。后来看我回复的大概不太情愿的样子，他就又说跟朋友改时间。emm这还差不多。
我们现在相处得很自然，有时候静静地不说话也不会太尴尬，当然有时太安静我还是会看看视频哈哈哈
