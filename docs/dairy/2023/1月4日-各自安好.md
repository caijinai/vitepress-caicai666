# 1月4日-各自安好

## 09:07

每次郎朗长时间不找我，我就会开始失落，有些负面情绪。一开始的时候很难过，会在夜里沉浸其中地瞎想，躲在被子里哭。难过的原因，好像是感受不到有人疼爱我，感觉没人会关心我，爱我。对啊，我就是这样一个需要从外界获取能量的人。

但是我自己消化情绪的能力比较强？所以一次又一次的，我已经慢慢习惯了，也慢慢知道这就是郎朗，他就是这样的性格和习惯，他不爱社交，不爱折腾，就爱宅着，如果不上班，他整个人就会down一点，也不找我聊天。他对工作，对同事对他的看法很在意，例如他会努力参加公司的团建活动，说不能不合群，即使我已经订好烧烤外在等他，我都怀疑他以前的恋爱是怎么过来的，他以前的女朋友跟他在一块能开心？
我是一个更爱自己的人，我知道他不爱我，知道我们之前没啥结果。也知道他这样的性格即使我们真的谈恋爱，我也不会觉得快乐，只会觉得更加伤心难过，因为一旦谈恋爱，对他的期待就会高很多。现在就不一样了，我对他没啥期待，所以他忽然之间的一些关心，就反而让我觉得惊喜。相处在一块的时候他就会对我很好，我们相处在一起的时候是舒服的，开心的。但是一旦分开就真的是没啥关系的两人。他对我来说就是一个“特别节目”，让我规律重复枯燥的生活有点其他的快乐~既然这样，那就这样吧
他有些优点的，就是真的心态很好，啥都不上心，无所谓，哈哈哈。就算是在被隔离，工作人员也安排不到位，没人关心到他的时候，他也一点不烦躁，我都有点不爽了，他还说可能封控的人太多了。工作人员有限。以及有时候我给他抒发一些负面情绪，负面新闻，他也会往好了想，安慰我，让我一下子就可以从那种情绪里出来，也让我可以换个角度思考自己的问题。就很佛，这样也能生活得更舒心吧。虽然他有时候就真的太佛太懒了，按他自己的话说，他是在活着，不是在生活。其实生活里没有那么多 必须 的事情，佛系一点（虽说看起来好像没啥追求的样子），心情好点。

他的性格，思想其实都很单纯，没那么多花花肠子，也不会胡思乱想。他的花花心思都总在谈单和做a上。其他事情都是很直接很简单的

他还有个很好的优点就是不浪费，给他买的食物，他一定努力吃光。他说他自己印象最深的一次吃撑，是叫妈妈给他买碗热干面，大份的。他又不想浪费，所以吃光光，但是撑到不行，笑死我。
