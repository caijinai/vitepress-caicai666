# 12月3日-来广州文化馆和海珠湖公园打卡逛逛

他在抖音刷到文化馆的视频，很好看
于是我们相约去逛逛
要先在公众号订票，我先预约好了
那天两三点到那里
确实很好看，建筑很古风，看到很多人都穿汉服或者明代的服饰过来，男的女的都有，真好看
还有些专门过来拍艺术照的
郎朗也给我拍了好多照片，路上还叫了路人给我们拍了合照☺️
走到高处俯瞰，真的好开阔，古楼与天接壤
里面有一些展览，介绍历史啥的，朗朗兴趣不大。我们很快就逛完啦，于是又去了海珠湖公园，就在附近

走啊走啊，走到了湖边，旁边有演出的舞台。
湖边没围起来，我们就做在岸边，吹着风，看着广阔的湖面，看着悠闲飞翔的鸟儿，看着湖对面的小蛮腰，听着旁边舞台传来的歌曲，会唱的就跟着一起轻轻唱，真的太舒服了
海珠湖生态不错，很多小鸟，小鸭子。还有虽然是冬天，还是有好看的花儿

往回走的时候还见到了好看的晚霞🌅太美丽啦

晚餐吃啥呢
他说棠下那边有胡辣汤和水煎包（河南老家的特色美食），于是我们就打车过去啦

这个店挂名是逍遥镇，看门口还有一些证书牌匾啥的，也不知道真假。不过店里工作的都是说的河南话

顾客很多，出菜很快，翻台率很高。

水煎包是现做现煎，一口大锅，煎得很快。其它的胡辣汤，油条啥的都是现成的，直接打就好。上菜快吃得快，大部分吃完就走不会多留

我们也是，跟别人拼桌了，他吃得快，吃完还等我好一会。胡辣汤又辣又烫，我吃半碗都费劲。不过他说感觉味道也不算正宗，大概就是吃个念想吧~

就此，结束行程满满的一天！😊😊☺️
