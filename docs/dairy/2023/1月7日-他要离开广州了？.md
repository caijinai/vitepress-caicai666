# 1月7日-他要离开广州了？

## 00:35

刚刚大干一场，做的过程，他说你真sao如果我不在广州了你怎么办，你就过来找我让我x你好不好，好不好。（我听到他要离开广州，整个心情都提不起来了）

之前他说下年有其他打算，我以为只是不在员村这家健身房做而已，还是会来广州的。结果现在他这么说…感觉他是不会回来了，也许年前再见面多一两次，以后我们就不会见面了。是不是以后也不会联系了呢……难过😔

- 以后每个节日，每个值得庆祝的日子里，没人陪我吃烧烤了
- 没人陪我健身跟我聊天
- 没人在需要仪式感的日子里送我礼物
- 没有宽广的胸膛可以抱抱
- 没人给我说甜言蜜语
- 每个周五的特别节目也没有了
- 没人会在楼道逮我，亲亲摸摸
- 没人会一边上课一边揩油
真的，难过的不是一点半点。我得到过他的身体，却从来没得到过他的人，没进入到他的生活里，他心理想很多事情都不愿意跟我说。

### 想问他的问题
1. 以前是不是没怎么做过，没啥经验
2. 跟我在一块，开心吗（嗐，他肯定说开心）
3. 会被催婚吗
4. 喜欢什么样的女生，谈恋爱的时候是什么样子的
5. 为什么不谈恋爱
6. 听田教练说你读书的时候不怎么理人，那你是怎么谈女朋友的
7. 微信上找不到你的时候可以打电话吗
结果一句都没问。。我真怂

他居然觉得我没有什么兴趣爱好，是不是因为这样觉得我很无聊呢~其实我有的。只是有些他不敢兴趣，我就不怎么提，比如咖啡

后面聊天，我问他下年你不来广州的话要去哪里，他总是说不确定，啥都不一定。但我记得他从很久前就说，这是我最后一次买他的课了，下一年就不在这里了。所以我觉得他这个决定应该已经定下来很久了。他应该不会回来广州了，就算回来他也不会来员村了。好难过啊。

忽然想最近的几天都跟他在一起，多看看他，毕竟以后也许就见不到了。

我怎么忽然有种失恋的感觉啊

也不知道是喝多个奶茶，还是想多了，早上躺在他的床上想这些想得我睡不着，早早就醒了

今晚好想见他，好想跟他聊天，发了微信给他也没回，我猜他压根都没登陆微信。今晚也是要很难入睡的感觉，唉。。。缺爱的我特别容易被人拿捏
