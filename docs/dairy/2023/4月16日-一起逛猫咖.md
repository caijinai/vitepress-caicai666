# 4月16日-一起逛猫咖

一个愉快且充实的周末
周六他们做考核结算，有几百块钱奖金。于是他说要带我去吃好吃的，哈哈哈。开心

下午先是出来逛猫咖。第一次逛猫咖，第一次见到这么多品种的猫咪，好可爱哈哈哈
猫咪都好懒，大部分都在睡觉
猫咪杯摸下巴好开心😊哈哈哈好可爱

![](dayone-moment:/video/83D9991E8E9E45BEBB2552521CF704EF)

晚上就去吃烤羊腿，刚去到非常饿，他还去买了猪头肉，鸡柳。于是，吃撑了哈哈哈
羊腿不错，调料也不会太咸，看来用的新鲜羊腿肉。还一起喝了酒。他可能一开始吃得太快，很快就吃撑了，去了趟厕所回来吃不下了。我就把剩下的肉打包了，当第二天的午餐带~完美

吃饱一起走回家，一路上也没牵手。我们出门的模式就是这样哈哈
他提着羊肉一走一甩，笑死。他让我走里面，别老走着靠马路边的。我走着走着就又走出去，他：你怎么老是走外边，万一撞到你怎么办。
嘻嘻，好的吧。虽然也只是一句简单的话，但是我就放大成那是爱呀。

希望一直有这么愉快的周末，一起出来约会
