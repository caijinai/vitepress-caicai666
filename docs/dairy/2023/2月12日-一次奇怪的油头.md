# 2月12日-一次奇怪的油头

我的头发糊到油烟机的油了。。。洗了好几遍头洗都洗不掉，一直油腻腻的
1. 一开始以为是自己没洗干净，于是周六那天在酒店洗了两次，还是油腻腻，心累
2. 怀疑是洗发水的问题，于是新买了一个海飞丝来洗，一样是洗了两次还是觉得头发黏
3. 查了小红书，说是可能是脂溢性皮炎。。。然后猪头就疯狂叫我去看医生。。。
4. 后来妹纸提醒说会不会是沾到油烟机了，哇！一语惊醒啊。对啊，我这头油得很不正常啊，就算脂溢性皮炎，刚洗好的那会总会是清爽的吧。最多就是出油快，哪有完全洗不干净的啊！而且我的油还是会黏手的那种。。。
5. 虽然已经洗了两次头，头皮都有点痛了，但还是一直想着，很难受。晚上做有氧也想着，所以做完有氧立刻去国人美发，给老板描述了一下我的情况，好在老板娘那里有 茶枯水\+小黄姜的洗发套餐（我查了茶枯粉很去油的），一上头辣辣的。总之老板娘洗了半个多小时，终于洗掉个八九成，头发根那里总算是清爽的了！救大命了真是。。。
6. 因为洗了两次头，头皮疼，那些姜水一上头可真辣，老板娘一直说没用很烫的水啊，怎么那么辣。。。。😂😂
7. 真的是没什么用的人生经验\+1
