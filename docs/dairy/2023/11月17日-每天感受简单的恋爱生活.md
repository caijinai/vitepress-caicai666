# 11月17日-每天感受简单的恋爱生活

工作日每天我会给他准备好早餐
他十点多起来洗漱，吃早餐。
他十一点20分出门，出门前会收垃圾，顺手一起带到楼下。（垃圾侠🌝）
出门前会亲亲我😚
前天他走到门口了，我已经回到我的办公区，他嗯了一下，撅着嘴，我过去亲
昨天他也是走到门口了，我送他到门口，他才想起来，我拽着他的袖子，他亲亲我
今天，起床好困，懒洋洋。他收垃圾的时候我坐在办公凳子上滑过去抱住他大腿。他笑，怎么抱我大腿呢。然后过了亲亲我额头，亲亲嘴。然后出门上班了

下班了

我会给他煮荞麦面，然后我们看看综艺，或者聊聊天。看他状态，他如果那一天上课多或者有开单就会开心点吧，我猜。
然后洗澡以后。他虽然不困，但是会过来床上陪我躺着，跟我聊天或者讲故事给我听。直到我困了想睡觉，有时候会等到我睡着他才会出来外面享受metime。可能因为他有问过我，如果我不过来陪你睡觉你会不会不习惯，我说会呀，会觉得身边空空的。（也可能是在之前的风栗园住的时候，我有时去睡觉他还在玩手机，我会去卖萌撒娇让他要陪我睡觉哈哈）
这种被人疼爱宠着的感觉真好。🥰

噢，对，他说我现在很会撒娇了，说话嗲嗲的。哈哈哈。我都想说，我一直都会啊哈哈哈
