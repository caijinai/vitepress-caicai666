# 5月16日-讨厌自己

感觉自己都有点魔怔了。从阳了狂吃以后体重涨到110，然后就一直在这个基础上下浮动。减脂大赛吃到122又减到105了。但是那段时时间太极端了，好难受，比赛结束之后我就狂吃。一下子就涨到108了。那段时间就狂吃狂吃狂吃。后来又五一了，伟桦过来，又是带着他吃吃吃。吃到112，又慢慢控制回109了。结果又出差澳门，我这恐怖的，收不住的食欲。出差一周，回来涨了四五斤。。。神经病啊你
