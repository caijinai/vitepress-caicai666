# 11月23日-第一次没陪我睡觉

他昨天给我报备说，今天要晚回来，每天日子过得太重复了。约了朋友打游戏，晚点回来。不能哄我睡觉了~昨天就聊了好多，聊了两个多小时，说明天就没得聊了，他要去打游戏了。我跟他异口同声说这是调休哈哈哈（之前他转发过一个搞笑视频给我看）

他说，你看我报备得多清楚

他说，现在这个鸭嘴兽工作室，太闲了。又没有分配资源给教练啥的，都得自己去开发，但是能开发的客户很有限。下个月如果新店开业晚，他就去找临时工干着，挣点。唉，就忽然感觉安定的生活又要有波动了。就很担心他一没有去工作，就又每天宅，打游戏，颓废，拖着拖着又一个月……希望他能像自己计划得这样干呗。我也要给他压力🙄

昨晚不知不觉聊了好多，聊到他说他爸爸好赌，年轻的时候有时候会挣了一年的钱，过年回来几天就输光了，然后回家跟他妈妈吵架，摔东西啥的。
他在一边不知所措，很不喜欢这样。他说他小时候都有点看不起他爸，长大以后有时他爸吼他，他就吼回去了。还说他爸，我小时候你这样赌博，摔东西，跟我妈吵架，你想过我的感受吗。他爸就不说话了
他以前从没说过这些，一直以为他的家庭简单幸福。原来也有这样的经历。感觉跟我也有点像，只是我的爸爸更过分，家暴。哎
他说起他跟他姐姐相差10岁，说应该是要追个儿子传宗接代才生的他，那我说：那你岂不是以后也得给你爸生个传宗接代的。他说：嗯，以后吧。（我的内心是不想生小孩的，听到这个忽然觉得我们不会走到最后，总有一天会分开。也许是因为他父母反对，因为我年纪比他大太多了，也许是因为他们都想要小孩，但我应该不会生…）

emm~不想太多了，现在开心就好。虽然我很想安定确定第就这么过下去，但是人最终都会是孤身一人。即使现在在一起好好的，但是也要降低心理期待，做好可能孤身一人的准备。

不过今晚一个人的夜晚真的略显孤寂，如果一直是这样，我大概会很想搬回去新村
