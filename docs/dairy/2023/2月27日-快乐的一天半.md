# 2月27日-快乐的一天半

他本来约的我周六晚上附近找个地方开房（我们最近的周末就是这样过的）
但是我好困就说等周日了。他说他找个好点的民宿公寓啥的。于是他找了一个能看到江景的，还能看到小蛮腰。景色是真的不错，很开阔，看着心情很好
他也难得没玩手机，登记入住以后我们就一直在聊天，聊聊风景，聊聊自己的经历啥的。
接着来了第一发，意犹未尽~
开着大屏幕，投影，点了烧烤，汽水。吃得尽兴
本来还说一会要出去走走，去外面吃饭。结果看着外面的风景，躺在柔软的被窝里，说不想出去了。我想也行啊，我也不想出去呢：还好我们两个都挺宅的哈哈哈
然后就一起看看综艺，看看电影，聊天。拍照，穿着和服拍。看小蛮腰，看无人机表演，真是开心。
接着来了第二发，满足了（虽然还想再来。。）
然后我看电影，他看小说。看完了再聊会天，聊好久，凌晨三点累了睡了。他还让我给他撒娇才能睡（果然男人都喜欢娇滴滴的小女人
今天早上十点多起来，叫了点茶点外卖吃，再稍微收拾下就退房了。（真舍不得呢，好想每个月都来）
因为不想中午回到公司大家还没下班，于是我说再走走，本以为他会留下我自己回去，他竟然说陪我一起走走哈哈。开心。我们就在两边坐了会，吹吹风，聊天。然后我就打车回去了。
真的好希望经常有这样单独相处的，又有一些特别风景看的约会
然后我真的好胖，上镜脸好大，我要加油减肥。今天还要学习穿搭，要变漂亮！（他在床上还问我，他瘦了，我是不是赚了哈哈）
发现他一个缺点~太懒了！竟然不下去拿外卖，哼。还好外卖是送上来的
