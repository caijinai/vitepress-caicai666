# 6月8日-如果总有一天会分开，那唯一能做的就是珍惜在一起的每一天

今天上课，我腰又不好了。他给拉伸，聊起天来。聊起他们有些教练离职了。他说也想，只是舍不得我~
他说明年不来广州了，一定不来了。
说要去郑州，离家近一点，出来这么多年了，也该回去了。
气氛很沉静，我有点伤心
说很可惜，可惜没有早几年遇见我。我嘴硬说，早几年遇上也没什么。
原来他真的从来没有把我塞到他的未来里
而我，我从来没有想过如果他离开这个城市我要飞奔相随
我们只是两个还没有归宿的人，在游离的时候，互相陪伴了一段。
我甚至不确定，自己是他的女朋友吗？我们在谈恋爱吗？像是又不像
好好珍惜在一起的时间，半年倒计时了
明天帮他过生日，也许是唯一能帮他过的一次生日了
要找个时间去横琴长隆玩，留下一些美好的回忆
