# 11月28日-他又双叒叕发烧了🤒

忽然就扁桃体发炎，也不知道是不是天天搭地铁容易感染病毒。
本来星期一晚上让他切鸡胸肉的，结果他病的虚虚的。我就不让他忙了，切鸡肉，洗碗，晾衣服啥的都干了。我可真是健康又勤快。他就不大好意思了，说真惭愧

他烧了一晚上，抱着我感觉好烫。凌晨退了点。今天凌晨他醒了，我也醒了，朦胧中还想着他不知道怎么样了，问他退烧了吗？他说好点了，我摸摸他的身体，也感觉凉了点了。（这一刻好像让他很感动，跟我提了两次，说我在朦胧中还记挂着他的身体）

他不舒服只能请假在家睡了。一天都蒙蒙的，他说今天休息了跟没休一样，一天都不知道在干什么。

晚上我运动完回来买了个体温计，让他测一下，37\.5，低烧。怪不得，我以为退烧了，原来还在持续烧，37\.5也是难受的，头疼，浑身肌肉酸疼。真是可怜。发烧了，胃口倒是挺好，吃了塔斯汀的香辣鸡腿汉堡，凉皮。吐槽鸡胸肉难吃。哈哈哈！
