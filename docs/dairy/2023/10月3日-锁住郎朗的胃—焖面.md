# 10月3日-锁住郎朗的胃—焖面

国庆这几天把焖面这道菜做得很熟悉了
一开始只是想试试焖面这种做法，就做了排骨焖面，没啥经验，水少了，面有点干。
河南本地人郎先生评价说焖面应该用五花肉，豆角应该用长豆角（我用的扁豆），还应该加豆芽，最后出锅的时候要加点香油。我说下次改良
然后应他的需求就改良做了一个五花肉豆芽版本的，他直呼好吃，好香，不够吃。哈哈哈
后面几天，每次问他想吃啥，他都是说焖面。绝了，这么爱吃呀
后来我都加豆芽，感觉豆芽也是灵魂之一。再在出锅的时候加蒜末，芝麻油，哎哟喂，是真的香。蒜末撒在热热的面里，一搅拌就激发出蒜香味了。在加上芝麻油，真的每次都觉得好香
这个菜做起来也方便，一锅出。我已经是个熟练工了，基本半个多小时就能做好。嘻嘻☺
