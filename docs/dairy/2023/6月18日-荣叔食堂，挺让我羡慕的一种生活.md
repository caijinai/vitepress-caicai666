# 无聊的生活
我的生活好像真的蛮无聊的。一闲下来，都不知道要干嘛好。也不会想着要精进自己，也不想给自己压力，发现我也没啥兴趣爱好，也不爱打游戏。虽说喜欢航天，喜欢历史，但是都没有朗朗熟悉啊。他怎么看了就能记得住呢，真是
之前一直都是工作日下了班就去健身，周末就备餐。周五晚上就例行去朗朗家，自从他搬家到风栗园，环境比较好，我也给一部分房租，我就比较爱去。
今天本来也想过去，他说约了朋友熬夜打游戏。真是~
因为下周端午节了，只上两天班，就算了，不备餐了。
所以我七点洗完澡就很闲，然后就觉得很无聊。我一闲下来，好像就想搞点需要动手的，让我看书我也不大想。。。一直看电视剧嘛，也无聊。。然后九点多，我就困了，躺着等睡觉😴
好无聊好无聊。但是又不知道自己到底想过什么样的生活。
朗朗这个月也不知道工作得怎么样，他说每个月总会烦躁几天，不想在健身房待着，也不想上课。然后就在想，如果他这个月干完又想走呢，他一走是不是就直接会河南去了，不待在广州了呢。那我的生活就更加无聊了
