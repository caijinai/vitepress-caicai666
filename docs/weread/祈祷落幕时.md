# 本书评论
## 书评 No.1
这个故事里最最令人憎恶的应该是博美的母亲，她才是这一切不幸的根源。只是苦难从来不由人。
父亲与博美用了极端的方式守护彼此，因为两人是黑暗夜里紧紧牵扯着的线，让自己知道，我与这世上的某个人有些亲密的关系。
父亲觉得因为自己，博美才会过上不幸的童年，而博美觉得父亲是用自己的人生来成全她的人生。然而两个人都过着让人无法想象的人生。
祈祷一切落幕，祈祷一切重来，祈祷不必再背负罪恶与谎言生存。
二刷这本小说，忽然觉得有点像 白夜行。
